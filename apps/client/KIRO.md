## Design System

This project uses a **takeUforward-inspired dark theme** with Tailwind CSS v4. All design tokens are defined in `src/styles/global.css` using Tailwind v4's `@theme` directive.

### Key Tokens
- Canvas: `#131316` | Primary: `#292418` | Accent: `#327CF6`
- Surface: `#1C1B1F` | Border: `#2A2925` | Text: `#FFFFFF`
- Fonts: DM Sans (body), Geist (labels), ui-monospace (code)
- Pill buttons, rounded cards (20px), micro-shadow elevation
- Mobile-first, generous whitespace, high contrast
