# Dashboard & Admin Pages Design Rules

## Scope
- Applies to `/admin/*`, user profiles, bookmark manager, and notification centers.

## Guidelines
- Uses elevated surfaces (`bg-surface-raised`) with subtle hairline borders (`border-border`).
- Tables must use responsive horizontal scroll wrappers (`overflow-x-auto`) with sticky headers.
- Forms use semantic inputs (`border-border`, focus ring `ring-accent/40`, clear labels).
- All destructive actions (e.g. Delete, Unpublish) require explicit confirmation dialogs.
