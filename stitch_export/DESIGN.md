## Brand & Style

This design system establishes an analytical, high-conversion visual framework tailored exclusively for high-stakes test preparation (SSC, Banking, Railways, and State Government examinations). The system eliminates superfluous decorative elements and media-heavy fixtures to focus entirely on cognitive speed, tabular clarity, rigorous performance metrics, and systematic practice workflows.

### Brand Personality & Philosophy
- **Authoritative & Scientific:** UI surfaces reflect precision engineering, test-taking efficiency, and data integrity. Every module exists to measure, assess, or elevate an aspirant's percentile.
- **Calm Under Pressure:** Competitive exams introduce high stress. The visual architecture uses composed, dependable tones with high legibility to avoid visual noise.
- **Direct & Conversion-Driven:** Hierarchy moves cleanly from exam discovery to diagnostic evaluation, test-pack access, and deep percentile analytics.

### Visual Style
- **Corporate / Modern Data-Dense:** Built on clean architectural grids, crisp subtle outlines, structured information densities, and disciplined surface layers.
- **Tabular Precision:** Optimized for scoreboards, question-palette matrices, sectional accuracy breakdowns, time-per-question telemetry, and cut-off benchmarks.

## Colors

The color palette centers on a disciplined teal primary coupled with deep slate neutrals, ensuring high contrast, enterprise authority, and effortless legibility across dense tabular interfaces.

### Functional Color Applications
- **Primary (`#0D9488`):** Anchors primary actions, active test tabs, active question indicators, percentile highlights, and confirmation states.
- **Secondary (`#0F172A`):** Defines high-prominence headers, key numerical metrics, data tables, and high-contrast navigation bars.
- **Tertiary / Energetic Accent (`#F59E0B`):** Reserved for pass subscription promotions, countdown timers, All India Rank badges, and streak milestones.
- **Neutral (`#64748B`):** Secondary metadata, exam categories, syllabus breadcrumbs, and structural lines.
- **Exam Testing Palette (`named_colors`):**
  - `correct-green` (`#10B981`): Correct responses, positive accuracy shifts, qualifying cut-offs.
  - `incorrect-red` (`#EF4444`): Negative marking warnings, incorrect questions, critical score deficits.
  - `unattempted-slate` (`#94A3B8`): Skipped items and neutral question palette anchors.
  - `review-purple` (`#8B5CF6`): Marked for review status in live mock test engines.
  - `cyan-accent` (`#06B6D4`): Comparative peer analytics, percentile curve graphs, and speed indicators.

## Typography

Typography relies uniformly on **Inter** to ensure maximum typographic legibility, robust tabular figure alignment, and predictable cross-platform rendering across mobile web, tablet consoles, and desktop exam engines.

### Numerical & Tabular Features
- Enable `tnum` (tabular numbers) and `zero` (slashed zeros) across all scoreboard components, question timers, test-pack counters, and analytical percentiles.
- Mathematical operators and test marking schemas (`+2.0`, `-0.50`) must maintain rigid vertical centering alongside question titles.

### Hierarchy & Usage Rules
- **Display & Large Headlines:** Used exclusively on landing page hero cards, pass subscription banners, and high-level analytics overviews (e.g., "All India Mock Test 04").
- **Tabular Stat:** Purpose-built for big performance numbers (e.g., Rank `142 / 48,209`, Percentile `99.4%`, Score `168.5/200`).
- **Labels & Microcopy:** Used with strict uppercase or sentence case pairing for status badges (`FULL MOCK`, `PREVIOUS YEAR`, `OFFICIAL CUTOFF`).

## Layout & Spacing

The layout is grounded in a fluid 12-column grid system designed to support two core user contexts: dense portal browsing (exam categories, pass selection) and full-screen mock testing console views.

### Layout Modes
1. **Catalog & Dashboard Grid (12 Columns):**
   - Max canvas container: `1280px`.
   - Desktop Gutter: `1.5rem` (`gutter-lg`), Margins: `2rem` (`margin-lg`).
   - Tablet (768px - 1024px): 8 Columns, `1rem` Gutter, `1.5rem` Margins.
   - Mobile (< 768px): 4 Columns, `1rem` Gutter, `1rem` Margins.
2. **Exam Practice Console (Split-Plane):**
   - Left plane: Fixed-fluid question viewing panel (spans 8 of 12 columns).
   - Right plane: Persistent question matrix and timer palette (spans 4 of 12 columns, collapsible to drawer on mobile).

### Component Spacing Discipline
- `space-xs` (4px): Micro gaps between question indices, badge padding, and icon attachments.
- `space-sm` (8px): Gaps between tabular row items, filter tags, and options within multiple-choice layouts.
- `space-md` (16px): Internal padding for standard test-series cards, question item boxes, and navigation rows.
- `space-lg` (24px): Padding for subscription plan containers and analytics metric summary cards.
- `space-xl` (32px) to `space-2xl` (48px): Section breaks between vertical content categories.

## Elevation & Depth

This system avoids heavy drop shadows and theatrical blurs, utilizing flat tonal layering paired with crisp 1px borders to maintain a rapid-scanning, official exam feel.

### Depth Hierarchy
- **Level 0 (Base Canvas):** Background tone `#F8FAFC`. Zero elevation.
- **Level 1 (Card & Module Layer):** Surface color `#FFFFFF` bounded by a solid 1px border (`#E2E8F0`). Used for test series cards, question banks, and scoreboard summary cards.
- **Level 2 (Active & Hover Cards):** Retains `#FFFFFF` with a subtle focused border (`#0D9488` at 40% opacity) and an ambient shadow: `0 4px 12px -2px rgba(15, 23, 42, 0.06), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Modals & Slide-out Question Palette):** `0 12px 24px -4px rgba(15, 23, 42, 0.1), 0 4px 6px -2px rgba(15, 23, 42, 0.05)` with a backdrop scrim of `#0F172A` at 60% opacity.

### Dividers & Outlines
- All separation within cards (e.g., separating test metadata from action footers) is performed via 1px solid `#E2E8F0` rules without shadow extrusion.

## Shapes

The design uses a clean, disciplined `roundedness: 2` (0.5rem base radius) across interactive surfaces. This geometry provides balanced modern softness while retaining crisp structure for high-density tables and technical question grids.

### Shape Scale Rules
- **Base Components (`rounded: 0.5rem` / `8px`):** Test series cards, input fields, test control buttons, modal frames, question options.
- **Micro Elements (`rounded-sm: 0.25rem` / `4px`):** Question palette number blocks (1 through 100), status tags, and tabular badges.
- **Large Surface Modules (`rounded-lg: 1rem` / `16px`):** Pass subscription feature callouts, score hero banners, and performance comparison cards.
- **Pills (`rounded-full: 9999px`):** Filter pills, category selectors (`SSC CGL`, `IBPS PO`, `RRB NTPC`), live status indicators, and timer badges.

## Components

### Buttons
- **Primary Action (Start Test / Unlock Pass):** Background `#0D9488`, text `#FFFFFF`, font `label-lg`, radius `0.5rem`, height `44px` (`36px` compact). Hover shifts background to `#0F766E`. Active state scales to `0.98`.
- **Secondary / Ghost (Save & Next / Review Later):** Outlined with 1px `#0D9488`, background transparent, text `#0D9488`. Hover fills `#F0FDFA`.
- **Destructive / Clear (Clear Response):** Outlined 1px `#E2E8F0`, text `#64748B`. Hover fills `#FEE2E2` and turns text `#EF4444`.

### Test Series & Pass Cards
- **Test Package Card:** Crisp white container with 1px border `#E2E8F0`. Header houses exam category tag (e.g., `SSC CGL Tier 1`), total test count badge (e.g., `450 Tests`), and language availability (`Hindi, English`). Body displays bulleted test breakdown (e.g., `40 Full Tests`, `120 Sectional`, `25 PYPs`). Footer houses pricing or `Attempt Free Test` CTA.
- **Pass Subscription Tier Card:** Prominent teal border (`#0D9488`) for recommended tiers. Features tenure selector (Monthly / 1-Year / 2-Year), total exam access indicator (`670+ Exams Included`), and immediate checkout action.

### Multiple Choice Options (MCQs)
- Container height minimum `48px`, padding `space-md`, border `1px solid #E2E8F0`, border-radius `0.5rem`.
- **Selected State:** Border `2px solid #0D9488`, background `#F0FDFA`.
- **Solution Review State:** Correct answer highlighted with `#10B981` border and `#ECFDF5` background; user incorrect selection highlighted with `#EF4444` border and `#FEF2F2` background.

### Question Palette (Test Engine Matrix)
- Grid layout: 5 columns on desktop panel.
- Dimensions: `36px x 36px` square tiles with `4px` border radius.
- States:
  - Green fill (`#10B981`): Answered.
  - Red fill (`#EF4444`): Not Answered.
  - Gray fill (`#94A3B8`): Not Visited.
  - Purple circle (`#8B5CF6`): Marked for Review.
  - Purple with green dot: Answered & Marked for Review.

### Performance Analytics & Scoreboards
- **Hero Score Summary:** Split 4-column bar displaying Total Score, All India Rank, Percentile, and Accuracy %.
- **Sectional Tabular Analysis:** Structured data grid detailing Section Name, Total Questions, Attempted, Correct, Incorrect, Marks Obtained, and Time Spent per question vs. Topper average.
- **Pacing & Speed Gauge:** Horizontal segmented bar contrasting time allocated against speed threshold per question category.
